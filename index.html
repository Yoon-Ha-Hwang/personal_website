Projects I Made

You can see a lot of my projects on my Github profile. (yes I did join on roughly the end of September)

Here is a short list of my featured projects, links to repositories:

  • Column Battler (formerly "Console-Based Card Game")

This is a project I worked on (also for Stardance) where I developed an intelligent bot called "Intellisense".
How it works: she (Intellisense is female) analyses each valid move, rates all of them, and then chooses the move with the greatest rating.
Of course Intellisense might look quite simple because there aren't so many moves to analyse (just look at Chess or Go, they have like millions of valid moves), but I still feel proud of it because it's quite easy to scale up and I got to know the art of game bots.

As of November 15, I am currently converting the Console Line Interface version into the Graphics User Interface version.
I also need to improve the logic more because a test-play player claimed a strategy that can win most of the times (haven't tested that one out yet, though)

  • Chalculator

This is a game where the user is presented a set of numbers and operators as well as the answer.
They must find the equation that uses those numbers and operators, that would form the answer value.

When I submitted to Stardance, users expressed frustration that the game is too difficult.
As a result I plan to make an update for a more varied difficulty setting: maybe one with addition and subtraction only?
Of course, plans aren't confirmed yet, but I also plan to make it into a Graphics User Interface version.

  • Virtual Shopping Interface

This is perhaps the best project I've worked on so far.
It simulates a shopping website, users buy made-up products and pay using made up information.

I'm definitely working on it in the future, it received a huge positive response in Stardance.
Although I emphasised that it doesn't collect any user data for the millionth time, some sceptics still find it creepy.
So, in addition to adding more products, I would also make some option to skip the information entering phase (likely a button to enter default values).

  • Base Converter

This is a simple tool to convert values across different bases.

I made it highly user-friendly, minimal distractions with clear instructions.
However, I got the suggestion to implement some sliders for more convenience. As a result, I plan to implement those at a later time.
It would definitely require a learning session! I don't know how to make those at the moment...
